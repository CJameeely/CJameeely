Interactive Reconstruction of Ruins

Live system Website Demo

An AI-assisted system for rebuilding heritage architecture after disaster

It reads the ruin, infers what is missing, and grows a new structure in a style the user chooses, marking what is observed, inferred or imagined. The first case is a fire-damaged shikumen lane in Shanghai, where one ruin becomes three repairs.

Background · Shikumen lanes, Shanghai

This project began with my experience volunteering at a summer camp for children from migrant families. Many live in aging shikumen lanes, where everyday hardship sits beside local history. Their brick-and-timber structure makes fire a constant risk.

First-hand interviews

Can ordinary people participate in deciding how a destroyed building returns?

Concept · AI reconstruction tool

A system that reads a ruin and a reference image, reconstructs spatial function first, then grows a new structure from the fracture. Each repair shows how confident it is.

Environment · Fire memory

Visualization · Almond, Paper Tube, Shikumen

The same burned shikumen is repaired with three references. Each row follows one style through the pipeline: model in Rhino, growth in Grasshopper, and final visualization on the web.

Architectural styles · Growth sequence

Scene setting · Lilong

Different sizes, one pattern. This shared rule lets the system grow from one house to a whole lane. The top row changes where the fire starts; the bottom row changes how the lane is repaired.

Technical process · Tools

Rhino + Python

I built a parametric Shikumen that can be burned and rebuilt, then wrote a Python pipeline (Shapely, NumPy) that grows three grammar skeletons across six burned houses.

Claude Vision

I used Claude to read the ruin photo and the reference image, and to output evidence, typology and six grammar parameters as data.

TouchDesigner

I first tested the growth as point-lines for projection mapping.

Web

I built an explorable 3D lane in the browser, where the repair grows back as particles and light and can be watched from any viewpoint.

Experiment · From one house to a lane

Test → Map → Sequence → Frame → Film

Lane testing verifies space, models and camera movement. The results are translated into eight connected stages, each combining data, reconstruction and cinematic direction to form the final storyboard.
