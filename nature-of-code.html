Nature of Code

The following projects were created in Nature of Code, an elective course in the Interactive Media Arts (IMA) program at NYU Shanghai. The course investigates how natural systems—physics, collective behavior, neural networks—can be modeled and reinterpreted through JavaScript (p5.js) and Processing. By merging algorithmic thinking with artistic exploration, it treats code not only as a tool, but as a creative material.
